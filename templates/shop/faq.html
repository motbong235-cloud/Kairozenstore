ព័ត៌មានសំខាន់មុនទិញ premium account

1. ទិញរួចបាន account ពេលណា?

បង់ KHQR / Wallet ជោគជ័យ → ប្រព័ន្ធផ្តល់ account ស្វ័យប្រវត្តិ។ មើលក្នុង Profile → Accounts / ប្រវត្តិទិញ។

2. ត្រូវ login Google ទេ?

ត្រូវ។ ដើម្បីរក្សាទុក order, wallet និង account របស់អ្នក។

3. បង់ហើយមិនទាន់បាន account?

រង់ចាំ 1–2 នាទី · refresh Profile។ បើនៅ pending សូមទំនាក់ Admin តាម Telegram ជាមួយ Order ID។

4. Wallet ប្រើយ៉ាងមិច?

Top up តាម KHQR → សមតុល្យចូល wallet → ទិញភ្លាមដោយមិនស្កេន QR ម្ដងទៀត។

5. Warranty / ប្តូរ account?

បើ account ដាច់ភ្លាមៗបន្ទាប់ពីទិញ (ក្នុងគោលការណ៍ហាង) ទំនាក់ Admin ជាមួយ proof។ មិនគ្របដណ្តប់ការប្រើខុស / share ច្រើន device លើសកំណត់។

6. ទូទាត់អ្វីខ្លះ?
